# ВОКСЕЛЬНАЯ БОЙНЯ — Arena Prototype 0.2

Брутальный воксельный FPS-прототип на Three.js в одном HTML-файле.
PS1-стиль хоррор + яркие неоновые акценты, воксельные эффекты (кровь, гибсы,
искры, дым, гильзы, дырки от пуль), волны врагов, синтезированный саундтрек.

**Темы: боди-хоррор.** Все твари генерируются процедурно прямо в коде
(мясо, рёбра, кости, светящиеся глаза, светящееся сердце, пасть на груди,
паразит-мешок) — никаких милых готовых скелетов. Анимация — процедурная:
переваливающая походка, спазмы, подёргивания, выпады, гибс/распад.

## Как запустить

**Вариант 1 (самый простой):** открыть `release/index.html` в любом браузере
(Chrome/Edge/Firefox). Всё в одном файле — интернет не нужен.
На Windows — просто двойной клик по файлу, установление ничего не требует.

**Вариант 2 (локальный сервер):**
```bash
cd vox-arena
python3 -m http.server 8000
# открыть http://localhost:8000/release/index.html
```
Локальный сервер нужен только для полноценного захвата мыши (pointer lock)
внутри встроенных превью некоторых платформ. Обычный браузер — открывайте файл напрямую.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение |
| `Мышь` | обзор (клик по экрану захватывает курсор) |
| `ЛКМ` | огонь |
| `R` | перезарядка |
| `Shift` | спринт |
| `Пробел` | прыжок |
| `Esc` | пауза / выход из захвата мыши |

Хедшот (верхняя часть) — ×2.6 урона. Красные аптечки +30 брони.
Шкала стиля (D→C→B→A→S→ULTRA) растёт за убийства и хедшоты, гаснет со временем.

## Твари

| Тип | Характер | Особенность |
|---|---|---|
| **СКОРОХОД** | быстрый худой бегун | видимое бьющееся сердце, рёбра, слишком длинные руки |
| **РЕЗАК** | сутулый мясник | костяное лезвие вместо предплечья, один глаз, хромота |
| **КЛЕЩ** | раздутый громила | пасть с зубами на груди, клешни, жует на бегу |
| **ПЛОД** | парящий паразит | три глаза, усицы, плюётся кислотой |

У каждой твари уникальная геометрия (сгенерированная с джиттером вершин —
две одинаковые твари не совпадают), подтёки крови из пасти, вспышка урона,
гибс или анимация смерти с распадом в воксели.

## Сборка из исходников

```bash
cd vox-arena
npm install          # three, esbuild, playwright (dev)
node tools/build.mjs # соберёт release/index.html
```

Тесты (headless Chrome, playwright):
```bash
npx playwright install chromium --with-deps
node tools/qa.mjs    # портреты тварей, вьюмодель, бой, гибсы, смерть, рестарт
```

## Структура

```
src/
  main.js          — состояние игры, цикл, ввод
  arena.js         — арена, коллизии, лучи против мира, аптечки
  enemies.js       — 4 типа тварей, ИИ, стиринг, снаряды, гибс/распад
  monsters.js      — процедурные тела (суставы) + процедурная анимация
  player.js        — движение, оружие, отдача
  weapon-model.js  — вьюмодель «Сектор-9»: единый связный корпус
  fx.js            — воксельные частицы (InstancedMesh), дым, декали, трассеры
  waves.js         — режиссёр волн
  audio.js         — SFX + музыка на WebAudio (без файлов)
  ps1.js           — низкое разрешение рендера + nearest
  textures.js      — процедурные PS1-текстуры (пол, стены, мясо, мембрана...)
  hud.js           — HUD, меню, настройки (на русском)
tools/
  build.mjs        — единый HTML-билд
  qa.mjs           — headless QA-тесты (скриншоты + проверки)
```

## Лицензии

- Все 3D-модели (твари, оружие) генерируются процедурно в коде —
  внешних ассетов нет, лицензионных ограничений нет.
- Звук генерируется процедурно в реальном времени (WebAudio), аудиофайлов нет.
- Код игры — без ограничений, делайте что хотите.
